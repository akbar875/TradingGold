# EA fondasi Aurum

EA fondasi menampilkan snapshot indikator closed-bar M15/H1/H4, market regime,
aksi WAIT dengan alasan terurut, serta kandidat M15 dengan ID dan skor heuristik
ketika setup teknikal lolos.
Input auto ditolak pada OnInit. Lihat [instalasi](../docs/INSTALL_WINDOWS_MT5.md)
dan [aturan strategi](../docs/STRATEGY_RULES.md).
Kompilasi harus diverifikasi di MetaEditor.
